# 体感网球（iPhone 当球拍 · AirPlay 投电视 · 第一视角 3D）

iPhone 握在手里当网球拍，挥动手机击球；画面通过 AirPlay 镜像投到电视上，手机屏幕变成球拍状态面板。
纯原生实现：Swift + SceneKit（3D）+ CoreMotion（挥拍识别）+ UIKit 外接屏幕场景，无第三方依赖。

## 怎么玩

1. 用 Xcode 打开 `TennisGame.xcodeproj`，选自己的 iPhone 运行（已配置 Development Team，首次装机需在手机“设置 → 通用 → VPN与设备管理”里信任证书）。
2. 主菜单 → “投屏到电视”查看步骤：控制中心 → 屏幕镜像 → 选电视。iOS 不允许 App 自己开启镜像。应用检测到外接屏幕后：**电视显示 3D 球场，手机显示球拍面板**。不投屏时 3D 画面直接显示在手机上。
3. 主菜单 → “开始游戏” → 握持与校准页，点 “Start calibration” 进入一键校准会话（连着电视时引导显示在电视上，手机只留 Cancel / Done）：
   - 第 1 步对正方向：按你挥拍的握法拿着手机，让**手机顶端**对准电视中央，保持静止 1.5 秒自动完成（也可点按钮）。只看顶端指向，屏幕朝左朝上都无所谓。
   - 第 2–8 步学习挥拍：按大字提示依次做 7 组动作（直挥、往左、往右、轻挥、用力、下砍、上挑各 5 次），每一步开始前有 2.5 秒准备倒计时，期间的挥拍不计；每识别到一次手机轻震。App 从你自己的样本里学出方向零点、左右分界、轻重分界、盖拍/开拍分界，存成个人档案。
   - 回到校准页可挥一下自检；左右反了点 “Mirror”。换握法、换手或方向漂了就重做。
4. “开始比赛”。对手发球后，球飞到你身前的黄圈时屏幕提示“挥拍！”（手机轻震），此时挥动手机。游戏中随时可 Pause / Resume、Recalibrate，或 Quit 回主菜单。

## 挥拍如何决定球的轨迹

不按精确角度算轨迹（手机上测不准，只会让人觉得“明明挥对了却打偏”），而是把一次挥拍按**拍面 × 力度 × 时机**分类查招式表，只有合适的组合才能过网、不打偏，再由程序反推一条能落到目标点的轨迹。

- 拍面（击球瞬间的仰角 = 60% 挥动路径倾角 + 40% 拍面倾角，往下砸就是盖拍、往上刷就是上旋）：默认 盖拍 < -20° ｜ 平击 -20°~8° ｜ 上旋 8°~35° ｜ 开拍面 > 35°；做过“学习挥拍”后以你的正常挥拍为上旋区中心，下砍/上挑样本决定盖拍/开拍分界
- 力度（手速）：Light / Heavy 两档，分界默认 3.6 m/s，做过“学习挥拍”后取你轻挥和用力挥的中点（`SwingProfile`）
- 时机：距球到达击球点 ±0.45 s 内算击中，±0.15 s 内算“时机好”；再早最多 1 s 会先记住、球到了自动打出

| 拍面 \ 力度 | Light | Heavy |
|---|---|---|
| 盖拍 | 下网 | 下网 |
| 平击 | 软球：过网但又短又慢，对手容易上来打 | 重炮 ✓ 落点 10 m，最快；时机不好 → 出界 |
| 上旋 | **吊球** ✓ 网前 2.5 m，落地就死；时机不好 → 吊得深，AI 可能追到 | 稳回 ✓ 8.5 m，最安全 |
| 开拍面 | 高吊 ✓ 9 m，高弧线 | 高吊 ✓ 10.5 m；时机不好 → 出界 |

- 方向：拍面朝向 + 挥动方向各一半，减去校准页采集的方向零点，±8° 为界分左 / 中 / 右。拍面轴在手机屏幕法线(z)和侧边(x)之间自动选与运动方向最一致的，屏幕朝前或朝侧握持都行。Light 瞄 ±2.4 m，Heavy 贴线瞄 ±3.2 m。时机误差只把落点拉偏最多约 0.6 m。提前击球把落点往左拉、晚了往右推，拉过边线就是打偏。
- 站位：不需要走动。玩家自动横移让球飞到球拍位置，短球会自动冲上去在反弹最高点接。手机只能精确测姿态和挥拍那一下的加速度，测不出走动这种持续位移，所以跑位必须自动。

## 难度等级

赢一局升一级（最高 6 级），记分牌上显示 LEVEL。等级越低对手越容易失误、反应越慢、跑得越慢、回球越老实：

| 等级 | 基础失误率 | 玩家每多回一拍 +失误率 | 反应时间 | 跑速 |
|---|---|---|---|---|
| 1 | 25% | +25%（回 2 拍后 75%，3 拍后 90%） | 0.7 s | 2.6 m/s |
| 2 | 15% | +18% | 0.6 s | 3.0 m/s |
| 3 | 10% | +12% | 0.5 s | 3.3 m/s |
| 4 | 6% | +8% | 0.45 s | 3.6 m/s |
| 5 | 4% | +5% | 0.4 s | 3.9 m/s |
| 6 | 2% | +3% | 0.35 s | 4.2 m/s |

对手失误一半打长出界、一半下网。参数在 `GameSession.params(for:)`。

## 怎么打赢 AI

对手有 0.4 s 反应时间、跑动速度有限、击球后站在原地不回中，并且会前后跑：

- 它在一侧时，往另一侧打（重击贴线更狠，但时机不好会打偏）。
- 它退在底线时，**吊球**（上旋 + 轻挥）让它追不到。
- 它被吊到网前后，上旋深球或高吊打它身后。
- 回合越长它越快、落点越刁钻，也更容易失误。

真实网球物理：重力、空气阻力、落地反弹、球网高度（中间 0.914 m，两端 1.07 m）、单打边线判定、没过网先落地算失分、两跳算失分。

## 画面上显示的信息

- **左上角 LAST SWING 面板**（常驻，每次挥拍闪一下）：手速 + Light/Heavy 力度条、拍面仰角 + 拍面类型、方向角 + 左/中/右、时机误差 + GOOD/OFF、这一拍的招式与落点。给玩家自我调节用。
- **右上角 TIP**：前 12 分内显示打法提示，根据当前局面（对手在哪一侧、在网前还是底线）和上一拍结果（太早、拍面朝下、软球…）变化，之后自动消失。数量在 `GameSession.tipsUntilPoints` 调。

- **来球轨迹**（白色点线）、**回球轨迹**（蓝色 = 界内，红色 = 下网/出界）、**落点标记**（绿圈界内 / 红圈出界）、撞网点红球。
- 左下角：来球的球速 / 方向角 / 仰角 / 落点；你回球的仰角 / 方向 / 球速 / 时机误差 / 过网高度 / 落点。
- 右上角：实时拍面仰角和水平方向表盘（指针 = 方向，竖条 = 仰角）。
- 右下角：俯视小地图，带球的飞行方向箭头。
- 第一视角里左下角的球拍模型会实时跟随手机姿态转动。

## AirPlay 延迟

屏幕镜像一般有 100–300 ms 延迟。手机面板上的“电视延迟补偿”（或手机画面上的“延迟补偿”按钮）会把挥拍时刻按该值往前推。感觉总是“太晚”就把补偿调大。

## 防止自动锁屏

`AppDelegate` 与 `SceneDelegate` 中设置 `UIApplication.shared.isIdleTimerDisabled = true`，游戏期间屏幕不会自动熄灭（每次回到前台都会重新设置）。

## 模拟器 / 调试

- 模拟器没有运动传感器：在画面上**滑动手指**模拟一次挥拍（左右 = 方向，上下 = 仰角，快慢 = 力度）。
- Debug 构建支持环境变量：`AUTOSWING="方向,仰角,手速[,提前秒]"` 自动挥拍；`START_STAGE=calibration|game` 跳过主菜单。例如：
  `SIMCTL_CHILD_START_STAGE=game SIMCTL_CHILD_AUTOSWING="0,15,5" xcrun simctl launch <设备id> com.lingqiao.TennisGame`
